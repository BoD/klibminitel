klibminitel

A Kotlin (Multiplatform) library to interact with the Minitel.

Usage

implementation("org.jraf.klibminitel:klibminitel:1.4.0")
val minitel = Minitel(filePath) minitel.connect { screen.disableAcknowledgement() screen.localEcho(false) screen.clearScreenAndHome() screen.print("Hello, World!") coroutineScope.launch { system.collect { e -> onSystemEvent(e, screen) } } keyboard.collect { e -> onKeyboardEvent(e, screen) } }
